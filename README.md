# DeadHunter
Мобильная браузерная игра без сборки и внешних зависимостей. Требуется Node.js 18+.

Запуск: `npm start`, затем http://localhost:5173. Порт задаётся через `PORT`.

Для генерации вакансий и ответов HR задайте только `OPENAI_API_KEY` в секретах сервера. Оба запроса используют GPT-6 Luna (`gpt-6-luna`) через OpenAI API; выбирать модель при деплое не нужно. Без ключа или при сбое API игра продолжится на локальных сценариях. Не добавляйте ключ в клиентские файлы.

При первом входе кандидат заполняет профиль. Профиль и отклики сохраняются в localStorage этого браузера. При повторном входе сразу открывается лента; для отправки отклика повторно заполнять анкету не нужно. Отредактировать данные можно через кнопку профиля в шапке.

Клиент: `index.html`, `app.js`, `style.css`. Экономика, исходы и сохранение — `game.js`. Прокси модели и раздача публичных файлов — `server.mjs`. Сохранение локальное для браузера; сервер не запрашивает реальные резюме и платёжные данные.
